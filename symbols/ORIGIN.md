# Symbol data

The [MIT license](LICENSE) covers UniSchematic's contributions to these
declarative files, including the catalog descriptions. Upstream symbol
definitions retain their CC0-1.0 provenance.

- `standard-0.3` derives from [rich-netlist/rnl](https://github.com/rich-netlist/rnl/tree/65b45cccbfb56a33684d63bdce69ffaa9d162536).
- `eda-0.1` derives from [rich-netlist/rnl-packages](https://github.com/rich-netlist/rnl-packages/tree/9978333c940a816661d4d9ae67ece4ec25279cb0/packages/eda-symbol/0.1).

The `location/` JSON records the source revision, file hashes, and upstream
license for each library. The fonts bundled with the executable have their
own notice at `xAct/fonts/LICENSE_DEJAVU`. Third-party dependency notices
are included in the release archive.
